# distributed qft

This project aim to bypass the exponential overhead suffered by classical quantum circuit procedure, LOCC. Instead of using statistic solutions such as quasi-probability distribution and Monte Carlo, we assume a quantum link between two Quantum Processing Units(QPUs). Also, we give qubits different role. In our project we simulate the distributed 8-qubit QFT. We use two 5-qubit QPUs and role one qubit in each QPU as communication qubit and the others are data qubits. We link them up by the quantum link. The link could share a EPR pair which allow us to do quantum teleportation while the computation. We utilize the technique called Telegate to deal with the cross-chip CNOT gate when we face it. Furthermore, we arrange a new routing method to lower the calculation burden compare to purely using telegate. This is what we called block swap.
